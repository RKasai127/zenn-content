# 利用したコマンド一覧

主に利用したコマンド一覧です。

:::message
ls,cd,mv等の基本コマンドは取り上げません。
解法や調査に利用したコマンドを主に取り上げます
:::

## file

### 何をしてくれるか

ファイルの種類を判別してくれるコマンドです。

### 何のために利用したか

CpawCTFでは、拡張子がないファイルが添付されていることが多々あります。
そこで、添付のファイルが何のファイルかを特定することで、次のアクションや調査につなげます。

fileコマンドのみの通常の出力だと、ファイルに関するメタデータが含まれており見づらいです。

```bash:bash
file -i ファイル名
```

とすることで、種別だけ出力することができ便利です。

## less

### 何をしてくれるか

出力結果等を一行ずつ表示してくるコマンドです。`|`でつないで利用しました。

### 何のために利用したか

メタ情報など一気に全部出力される場合に、一行ずつ確認する用途で利用しました。
全量確認した後に`/`で、検索したりする用途で利用しました。
`?検索文字列`で後方検索もできるようですが、利用しませんでした。

## grep

### 何をしてくれるか

出力結果等を検索する用途で利用しました。

### 何のために利用したか

全量をみたいときは`less`を利用し、検索だけしたい場合は`grep`を利用しました

## strings 

### 何をしてくれるか

主に、wordファイル(.doc)等のバイナリファイルから人間が読める文字だけを取り出してくれます。

### 何のために利用したか

上述した`less`や`grep`と組み合わせて、`flag`が存在しないか、またヒントとなるような情報がないかを調査するために利用しました。

# 利用したツール一覧

## catdoc

### 何をしてくれるか

word(.doc)ファイルから文字列を取り出してくれます。

### 何のために利用したか

word(.doc)ファイルからテキストデータを抽出するために利用しました。

## antiword

### 何をしてくれるか

word(.doc)ファイルから文字列を取り出してくれます。

### 何のために利用したか

word(.doc)ファイルからテキストデータを抽出するために利用しました。
上述した、`catdoc`との違いとして`antiword`はwordファイルの構造を忠実に再現してくれます。個人的には`antiword`のほうが得れる情報が多いと感じました。
実際にCpawCTFでは、`antiword`からヒントを得て`flag`を見つけれたケースがありました。
(これ以上はネタバレになるので、気になった方はぜひやってみてください)

## binwalk

### 何をしてくれるか

バイナリファイルの中に埋め込まれたファイル(画像)等を抽出してくれます

### 何のために利用したか

バイナリファイルの中に埋め込まれたファイル(画像)等を抽出するために利用しました
ネタバレになるため、これ以上は記載しませんが、自動検出モードで利用しました。

```bash:bash
binwalk -e ファイル名
```

## exiftool

### 何をしてくれるか

Exif情報を抽出してくれます。

### 何のために利用したか

jpeg画像からExif情報を抽出し、`less`でヒントとなる情報が記載されていないか確認するために利用しました。

Exif情報については以下のサイトの解説が分かりやすかったです。

https://flets-w.com/chienetta/communication/nrt_ser-cat36_photo-exif.html

## tshark

### 何をしてくれるか

パケット情報を記録してくれているファイル(pcap)から、内容を出力してくれます

### 何のために利用したか

pcapファイルからパケット情報の中にflagが隠されていないかを調査するために利用しました。
主に、

```bash:bash
tshark -r pcapファイル
```

で通信記録の全体をつかみ、気になった通信の番号を`-Y`で条件指定(フィルタ)し`-x`で16進数表示にして確認するといった手順で調査していました。

```bash:bash
tshark -r pcapファイル -Y 'frame.number==1' -x
```
